CPU 的命令怎样变成 GPU 的计算

例子是计算 c = a + b。蓝色区域就是 CPU 和 GPU 之间的控制模块，跟着 ①～⑦ 的顺序看。

按顺序读一遍

  1. CPU 把 4 条命令写进命令队列，写完就可以去做别的事。
  2. CPU 按门铃，告诉 GPU 有新命令。
  3. 门铃叫醒命令处理器。
  4. 命令处理器从队列里逐条取命令，并判断能否执行。第 3 条要等 a、b 传完。
  5. 传数据的命令交给拷贝引擎，计算命令交给任务分发。
  6. 任务分发把计算拆成小块，分给 SM 0 和 SM 1。
  7. 做完后记录完成状态，CPU 查询时就知道结果好了。

在你的项目里：这张图的流程已经能跑通，但蓝色的控制模块只有 C++ 代码，还没有写成电路。
