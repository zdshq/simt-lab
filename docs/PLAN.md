# 实施计划

## 目标和边界

实现能执行自定义 128 位指令的 C++ 功能级 SIMT 模拟器，采用 curryGPU 的 ISA → ISS → ITS → 访存同步 → MMA → 组合工作负载的开发顺序。以两个可配置 SM 为默认组织，32 lane/warp，支持真实的分支、跨 warp 协作和张量数据路径。使用 Git 保留分阶段设计、实现和验证过程。

功能指令步数仅用于诊断和终止保护，不是硬件周期。独立数值参考按本项目公开的运算规范计算，不冒充作者未公开的精确实现。公开文章中的 ISA 全集、RTL、完整 PTX/CUDA 兼容和性能预测不属于本次功能模拟器交付；不能用当前程序通过的测试声称这些能力。

## 验证原则

1. 机器码由实际编码器生成并经过实际 C++ 解码执行，不用 Python 直接替代设备计算。
2. 对同步明确、结果与执行顺序无关的测试，比较至少三种确定调度顺序；原子旧值等顺序敏感行为按独立类别测试。
3. 稀疏内存快照按稳定顺序输出，未写地址与写零地址的规范化一致。
4. MMA 的独立参考使用整数或精确二进制/有理运算检验所声明的舍入规则；普通数学参考另外使用容差。
5. 测试非法编码、越界、未初始化屏障、屏障参与错误和超出步数等失败路径。
6. 明确区分功能完成、测试通过和未支持特性；任何阶段更新都须有当前可复现的命令证据。

## Git 规则

每阶段先实现并运行针对性的验收，再提交代码、测试、规范和开发记录。阶段中发现的实质性问题可单独提交修复。编译产物、临时快照、下载数据和本地 HTML 不提交；不改写已提交阶段的历史，不自动推送远程。
